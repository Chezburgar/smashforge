Make the game look like the launcher

The main menu, its buttons and the screen you stare at while the game loads are all textures, so they can all be replaced. Pick a palette and Orion draws the set to match the launcher: flat buttons with one thin border instead of grey bevels, a wordmark with a hairline rule instead of the stone logo, a calm sky instead of the countryside, and menus that are not the inside of a dirt block. It is deliberately not Minecrafty.

What you see below is drawn from the actual files the pack will contain, laid out the way the client lays them out — so the preview is the pack, not an impression of it. The one approximation is the main menu's sky: the client washes that toward white, and the preview copies it by eye, so you are not shown a dark sky the game will never draw.

Put it in the game

Then turn it on. In the client: Options → Resource Packs, hover your pack, and choose Select this resource pack. The loading screen changes the next time the game starts; the menu changes as soon as resources reload.

Only one of those reaches the game itself. The lettering is a single texture, so replacing it changes chat, item names and signs along with the menus — there is no way to have one without the other, and the checkbox above turns it off. Everything else here is menu furniture and cannot show up in a world. The hotbar in particular stays exactly as your client draws it: the buttons share its file, so Orion copies the rest of that file from the client instead of redrawing it.
A resource pack can change pictures, sounds and text files, and nothing else. Where things sit is compiled into the client, which is signed and cannot be edited without breaking that signature — so button positions and sizes stay as they are, and so do the client's own corner labels (Minecraft 1.8.8, EaglercraftX, the Mojang copyright), which are strings in the bundle rather than files in a pack. Orion's own loading screen, the one before the game appears, is part of the launcher and already matches.
