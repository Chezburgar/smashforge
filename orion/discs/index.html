Print a record

Jukeboxes play the twelve music discs the game ships with. This replaces the music on them: pick a track, put it on a disc, and every jukebox in every world you load plays yours instead.

Bring an audio file you already have, or have one generated here. It also comes with the printer as a block you can place: the jukebox, reskinned and renamed.

1 · Make a track

A synthesiser, not a library: pick a mood and it writes a track from scratch in this tab. It is the same generated soundtrack engine that SMASHFORGE runs on, stretched out to record length. Nothing is uploaded and nothing is fetched.

Any audio file the browser can play: mp3, ogg, wav, m4a. It is checked by actually decoding it, which is what the game will do too, so if it passes here it plays there, and it goes into the pack unchanged so it stays its original size.

A song from YouTube cannot become a disc. Orion Music plays through YouTube's own player, which never hands the audio to the page — and the YouTube API has no endpoint that returns a sound file. So there is no way for this to take a link and make a record out of it. If you have the track as a file, drop it in here.

2 · The twelve discs 0 printed

Each one is a disc that already exists in the game. Fill in as many as you like — the ones you leave alone keep their original music, so printing two discs does not silence the rest.

3 · The printer, as a block

A machine to put the records in. This turns every jukebox into an Orion Disc Printer — new look, new name — so there is a printer in the world that plays what you printed.

It is a reskin, not a new block. A resource pack can change what a block looks like and what it is called, and nothing else — a genuinely new block is code, and this client is signed, so there is nowhere to put code. The jukebox is already the machine that plays records, so it is the one dressed up. It behaves exactly like a jukebox: right-click with a disc, right-click again to eject.

4 · Print it

How to actually hear it

  1. Print the pack

    Put it in my game writes it straight into the client's own resource pack storage, so there is no file to find and no folder to open.

  2. Turn it on

    Launch the client, then Options → Resource Packs, and move your pack from Available to Selected. It stays on from then on.

  3. Put a disc in the printer

    Any disc you printed over, into any jukebox — which now looks and reads as an Orion Disc Printer. In creative both are in the inventory (search printer for the block, record for the discs); in survival the discs still come from a creeper killed by a skeleton, same as always.

Why the discs are short. A generated track is written as uncompressed audio, which is about 44 KB a second — a ninety-second disc is roughly 4 MB. A file you bring is copied in exactly as it is, so an mp3 stays mp3-sized. If you want twelve long discs, bring twelve mp3s.

Disc Printer — part of Orion Client. The music is generated in your browser and the pack is built there too; nothing is uploaded unless you publish it.
