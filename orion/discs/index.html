Print a record

Jukeboxes play the twelve music discs the game ships with. This replaces the music on them: pick a track, put it on a disc, and every jukebox in every world you load plays yours instead.

Tracks come from Orion's own music — the same generated soundtrack the rest of this site runs on, written out at record length — or from an audio file you already have.

1 · Make a track

Pick a mood and press Render. Nothing is uploaded — the music is made in this tab.

Any audio file the browser can play: mp3, ogg, wav, m4a. It is checked by actually decoding it, which is what the game will do too, so if it passes here it plays there.

3 · Print it

How to actually hear it

  1. Print the pack

    Put it in my game writes it straight into the client's own resource pack storage, so there is no file to find and no folder to open.

  2. Turn it on

    Launch the client, then Options → Resource Packs, and move your pack from Available to Selected. It stays on from then on.

  3. Put a disc in a jukebox

    Any music disc you printed over. In creative the discs are in the Miscellaneous tab; in survival they come from a creeper killed by a skeleton, same as always.

Why the discs are short. A generated track is written as uncompressed audio, which is about 44 KB a second — a ninety-second disc is roughly 4 MB. A file you bring is copied in exactly as it is, so an mp3 stays mp3-sized. If you want twelve long discs, bring twelve mp3s.
