Getting it into the game

  1. Download it

    Press Download skin. You get a 64×64 PNG — the format Minecraft and Eaglercraft both expect.

  2. Add it in the client

    Launch the client, then on the main menu choose Edit Profile → Add Skin and pick the file you just downloaded. It stays in that browser, so you only do this once per device.

Orion cannot install the skin for you: the client keeps its own skin library inside the game, and the only way in is its own Add Skin button. Two clicks, once.

Skin Designer — part of Orion Client. Everything happens in this browser; nothing is uploaded, and the starting body is generated in code rather than copied from anyone's skin.
